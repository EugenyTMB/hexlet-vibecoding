# hexlet-vibecoding

## Калькулятор суточной нормы калорий

Откройте index.html в браузере. Установка не нужна.

Форма: пол, возраст (18–120), вес в кг, рост в см, 5 уровней активности и цель.

Миффлин — Сан Жеор: основной обмен = 10 × вес + 6.25 × рост − 5 × возраст + 5 для мужчин, −161 вместо +5 для женщин.
Поддержание = основной обмен × активность (1.2 / 1.375 / 1.55 / 1.725 / 1.9).
Цели: похудение ×0.85, поддержание ×1, набор ×1.15.
Округляется только отображение. Изменение параметров скрывает старый результат. Данные не сохраняются и не отправляются на сервер.

Расчёт ориентировочный, для взрослых.
Источник формулы: https://www.hhs.texas.gov/sites/default/files/documents/common-comparative-standards-for-rds-ltc-settings.pdf

## Запуск одного файла

Скачайте index.html (Raw → сохранить файл) и откройте его двойным щелчком. Весь код расчёта включён в HTML, поэтому app.js рядом не требуется. app.js сохранён как отдельная копия для чтения и проверки формулы; при изменениях поддерживайте обе копии одинаковыми.

Если адрес содержит ?sex=... после нажатия кнопки, используется старая версия HTML без загруженного обработчика: скачайте свежий index.html.

## ИМТ и пример меню

ИМТ = вес (кг) / рост (м)². Категории взрослых: <18.5, 18.5–<25, 25–<30, ≥30. Категория определяется до округления. ИМТ не различает мышечную и жировую массу и не является диагнозом.

После расчёта показан пример завтрака, обеда и ужина с граммовками. Это отдельный иллюстративный рацион на примерно 1758 ккал, а не персональная рекомендация и не автоматическая подгонка под цель. Калории блюд считаются из порций и приблизительных значений на 100 г; реальные значения зависят от продукта и приготовления. В списке указано, какие продукты взвешиваются сухими, а какие готовыми. Масло учтено отдельно.

Источники общих принципов:
- ИМТ: https://apps.who.int/nutrition/landscape/help.aspx?helpid=420&menu=0
- Разнообразие продуктовых групп: https://www.nhs.uk/live-well/eat-well/food-guidelines-and-food-labels/the-eatwell-guide/
