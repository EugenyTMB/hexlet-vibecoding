# hexlet-vibecoding

Учусь вайбкодингу — здесь мои эксперименты.

## Калькулятор калорий

Простое приложение на HTML, CSS и JavaScript без зависимостей.

### Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Установка и сборка не нужны.

### Возможности

- Добавление продукта, веса и калорийности на 100 г.
- Расчёт калорий каждого продукта и общей суммы без накопления ошибок округления.
- Удаление продуктов и очистка списка.
- Сохранение списка в localStorage браузера.
- Адаптивный интерфейс на русском языке.

Формула: `калории = вес в граммах × ккал на 100 г / 100`.
Например, 150 г продукта с калорийностью 110 ккал на 100 г = 165 ккал.

Данные хранятся только на устройстве пользователя. Если хранилище недоступно, калькулятор продолжает работать без сохранения.
